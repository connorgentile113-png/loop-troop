Education World

A Minecraft-style world you can walk around right here in this page. It runs on Eaglercraft — an open-source project that puts a Java Minecraft client on top of the same JavaScript your quests use. There is nothing to install and nothing to sign up for: one canvas, one connection to the camp server.

Step 1

Pick a camper name

Other players will see this name in the world. It stays in this browser — no account, no email.

3–16 characters, letters and numbers.

Step 2

Enter the world

The world loads in this page. Nothing is downloaded from another website — the client ships with Loop Troop.

Open inside its own tab

First load takes a minute: the client is about 33 MB and comes from this site. After the menu appears, click Multiplayer if you are not dropped into the world already.

wss://looptroop.eagler.host

  1. Your saved name is filled in for you.
  2. Choose Multiplayer → Education World.
  3. If the list is empty, paste wss://looptroop.eagler.host under Direct Connect.

Use the whole address, including wss://. A message like handshake timed out usually means the network is blocking the address rather than the world being gone; press Test connection to tell which, and Enter again to retry.

Loading Education World… 0s. This is a big download the first time; later visits are instant.

Walk with WASD. Keys belong to the game while it is on screen — if nothing moves, click the game once to hand it your keyboard.

Before you build

A grown-up should be in the room. This is a public, unmoderated server: anyone with the address can join, build, and chat. There is no profanity filter and no chat log. Treat it like a shared school playground, not a private space — never share your real name, school, address, or photos.

Eaglercraft is a third-party open-source project and is not affiliated with Loop Troop or Mojang. The client is served by this site; the world itself is saved by the camp server, not by this page. Loop Troop stores only your camper name, in this browser.
